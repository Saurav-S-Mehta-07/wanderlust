# ChillCasa

## Description
ChillCasa is a modern property listing and booking web application, designed to provide users with an intuitive and seamless experience for browsing, searching, and booking vacation rentals. It is a clone-inspired project based on popular booking platforms.

## Features
- Browse property listings with images, descriptions, and prices
- Search listings by location, category, and keywords
- Filter listings by categories such as "Amazing Pools", "Beachfront", etc.
- User-friendly UI with responsive design for all devices
- Flash messages for user notifications
- Integration with maps for property locations
- Fully functional backend for managing listings
